# Backlog SEO / GEO

Ce backlog est tiré de l'audit automatique (`npm run audit`) et comparé à la stratégie
du 22 juillet (`docs/strategie-geo-seo/`). La liste priorisée et le statut de chaque item
sont dans `manifest.json`.

La routine hebdomadaire relance l'audit : si un chiffre baisse, l'item avance.
Un item passe à `done` quand sa PR est mergée.
